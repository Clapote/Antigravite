Politique de confidentialité / Privacy Policy

Application : Antigravité (éditeur : Lucas Peutot) · Dernière mise à jour : 27 novembre 2026 · Contact : Antigravite@proton.me

1. Philosophie 100 % locale

Antigravité est un logiciel de bureau pour Windows fonctionnant localement sur votre ordinateur. L'application ne comporte ni compte utilisateur propriétaire, ni publicité, ni traceur analytique, ni télémétrie, et n'exploite aucun serveur distant tiers pour collecter ou héberger vos tâches, projets, notes ou événements.

2. Données Google accédées et finalités exactes

Si vous choisissez volontairement de connecter votre compte Google Agenda depuis Paramètres > Connexion Google & Mises à jour, Antigravité demande uniquement les autorisations (scopes OAuth 2.0) suivantes :

Scope Google OAuth 2.0 Utilisation exacte dans Antigravité
https://www.googleapis.com/auth/userinfo.email
https://www.googleapis.com/auth/userinfo.profile		 Afficher votre nom et votre adresse e-mail dans l'écran Paramètres afin d'identifier le compte connecté.
https://www.googleapis.com/auth/calendar.readonly Lister vos calendriers Google pour vous permettre de choisir celui à synchroniser, et lire les événements à afficher dans l'Agenda Antigravité.
https://www.googleapis.com/auth/calendar.events Créer, modifier ou supprimer un événement dans le calendrier Google sélectionné lorsque vous effectuez une action dans l'Agenda Antigravité.

3. Stockage, sécurité et absence de partage

  • Stockage exclusivement local : Vos événements synchronisés, tâches, notes et jetons OAuth restent enregistrés uniquement sur votre ordinateur.
  • Chiffrement des jetons : Les jetons OAuth Google sont chiffrés localement à l'aide de l'API système Windows DPAPI (via Electron safeStorage) et conservés dans le dossier privé de l'application (userData/google_auth/auth_data.enc).
  • Aucun partage ni transfert tiers : Vos données Google ne sont jamais vendues, louées, transférées à des tiers, ni utilisées à des fins publicitaires ou d'entraînement d'IA.

4. Conservation et suppression des données

  • Vous pouvez déconnecter votre compte Google à tout moment depuis Paramètres > Connexion Google & Mises à jour : cela supprime immédiatement les jetons OAuth locaux et les événements importés depuis Google.
  • Vous pouvez également révoquer l'accès d'Antigravité à tout moment depuis votre compte Google : myaccount.google.com/permissions.

5. Conformité Google API Services (Limited Use Disclosure — English)

Antigravité's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Data Accessed: Google Account email/name (for connection status display), Google Calendar list, and calendar events in the user-selected calendar.
  • Data Usage: Used strictly to display the user's schedule inside the local desktop Agenda view and synchronize user-initiated event creations, edits, or deletions back to their selected Google Calendar.
  • Data Storage & Protection: All data and OAuth credentials are stored solely on the user's local Windows machine. OAuth tokens are encrypted via Windows DPAPI (Electron safeStorage). No developer backend or external server receives user Google data.
  • Data Sharing: None. Google user data is never sold or shared with any third parties.
  • Data Deletion: Disconnecting inside the app clears local OAuth tokens and synced Google event caches immediately; access can also be revoked via Google Account security settings.
